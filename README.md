# Лабораторная работа № 7

Тема: передача данных между запросами пользователя с помощью Cookie и объекта сессии.

## Приложение

Стартовая JSP-страница запрашивает имя пользователя и цвет страницы. После отправки формы оба значения сохраняются в Cookie со сроком жизни семь дней. В объекте `HttpSession` увеличивается счётчик обращений и записывается дата последнего обращения. Страница `result.jsp` выводит сохранённые Cookie и атрибуты текущей сессии на фоне выбранного цвета.

## Сборка и запуск

Нужны JDK 17 или новее, Maven и Apache Tomcat 9.

```sh
mvn clean package
```

Скопировать `target/lab7-webapp.war` в папку `webapps` Tomcat. После развёртывания приложение доступно по адресу `http://localhost:8081/lab7-webapp/`.

## Проверка

При работающем Tomcat выполнить:

```sh
python check_app.py
```

Скрипт проверяет создание Cookie, сохранение значения цвета, сессионный счётчик и дату последнего обращения.
